# Тренировки в Telegram

Это личный Telegram-бот для планирования домашних или зальных тренировок. Он помогает один раз собрать свою программу, а потом сам присылает тренировку по выбранному расписанию, показывает подходы и ведёт статистику.

Бот работает только пока запущена программа на компьютере или сервере. Для первого запуска не нужно уметь программировать: ниже всё расписано по шагам.

## Что умеет бот

- Создавать **группы мышц**: например, «Спина», «Ноги» или «Грудь».
- Добавлять упражнения в каждую группу: название, количество подходов, цель и время отдыха.
- Создавать **тренировочные дни** — готовые планы вроде «Спина + бицепс» или «Ноги».
- Выбирать дни недели, время напоминания, группы мышц и количество упражнений из каждой группы.
- В день тренировки автоматически присылать план в Telegram.
- Позволять отмечать выполненные подходы прямо кнопками в сообщении с тренировкой.
- Подбирать упражнения по очереди, чтобы одни и те же движения не повторялись слишком часто.
- Показывать текущую серию тренировок, личный рекорд, число выполненных подходов и календарь текущего месяца.
- Отправлять напоминание, если тренировка начата, но ещё не закончена.
- Настраивать время относительно Москвы: например, Самара — `/timezone +1`.
- Сбрасывать только историю и статистику, не удаляя упражнения, группы мышц и планы тренировок.

## Как это выглядит в обычной жизни

1. Вы добавляете группы: «Спина», «Грудь», «Ноги».
2. Добавляете упражнения: «Подтягивания», «Жим лёжа», «Приседания».
3. Создаёте тренировочные дни и выбираете, когда они должны приходить.
4. В назначенное время бот присылает тренировку.
5. После каждого подхода нажимаете кнопку подхода в сообщении.
6. Когда все подходы выполнены, тренировка закрывается, а статистика обновляется.

# Первый запуск — пошагово

## Что понадобится

- компьютер с Windows, macOS или Linux;
- интернет;
- установленный **Python 3.12 или новее**;
- аккаунт Telegram;
- примерно 10–15 минут.

> **Важно:** бот должен быть запущен на устройстве, которое не выключается в часы тренировок. Если закрыть окно с программой или выключить компьютер, бот не сможет присылать напоминания.

## Шаг 1. Скачайте проект и откройте его папку

Скачайте проект в отдельную папку, например `gorilla-sport-bot`.

Откройте терминал **внутри этой папки**:

- **Windows:** в Проводнике откройте папку проекта, кликните по пустому месту правой кнопкой мыши и выберите «Открыть в Терминале».
- **macOS / Linux:** откройте приложение «Терминал» и перейдите в папку проекта командой `cd`.

## Шаг 2. Установите Python

1. Откройте сайт [python.org/downloads](https://www.python.org/downloads/).
2. Скачайте Python версии **3.12 или новее**.
3. На Windows при установке обязательно поставьте галочку **Add Python to PATH**.
4. После установки закройте и снова откройте терминал.

Проверьте, что Python установлен:

```bash
python --version
```

На Windows, если команда не сработала, попробуйте:

```bash
py --version
```

Должно появиться что-то вроде `Python 3.12.x` или более новая версия.

## Шаг 3. Установите uv

`uv` — небольшая программа, которая сама скачает всё необходимое для бота.

### Windows

В терминале выполните:

```bash
py -m pip install uv
```

Если команда `py` не работает, используйте:

```bash
python -m pip install uv
```

### macOS / Linux

```bash
python3 -m pip install uv
```

## Шаг 4. Создайте бота в Telegram и получите токен

Токен — это секретный пароль, который позволяет этой программе управлять вашим ботом.

1. Откройте Telegram.
2. Найдите официальный бот **@BotFather**.
3. Нажмите **Start** или отправьте `/start`.
4. Отправьте команду `/newbot`.
5. BotFather попросит название. Например: `Мои тренировки`.
6. Затем придумайте имя пользователя для бота. Оно обязательно должно заканчиваться на `bot`, например `my_training_helper_bot`.
7. BotFather пришлёт строку вида:

   ```text
   123456789:AAExampleTokenHere
   ```

8. Скопируйте эту строку целиком. Это и есть токен.

> **Никому не отправляйте токен.** Не публикуйте его в чатах, скриншотах или на GitHub. Если токен случайно попал к другому человеку, сразу откройте @BotFather и создайте новый токен командой `/revoke`.

## Шаг 5. Создайте файл с настройками

В папке проекта есть файл `.env.example`. Нужно сделать его копию с именем `.env`.

### Windows: командная строка

```bash
copy .env.example .env
```

### Windows: PowerShell

```powershell
Copy-Item .env.example .env
```

### macOS / Linux

```bash
cp .env.example .env
```

Теперь откройте созданный файл `.env` в Блокноте, VS Code или любом текстовом редакторе.

Найдите строку:

```env
BOT_TOKEN=123456:replace_me
```

И вставьте вместо `123456:replace_me` токен, который выдал @BotFather. Например:

```env
BOT_TOKEN=123456789:AAExampleTokenHere
```

Сохраните файл.

Остальные строки в `.env` для первого запуска менять не нужно:

```env
DATABASE_URL=sqlite+aiosqlite:///./workout_bot.db
DEFAULT_TIMEZONE=Europe/Samara
SCHEDULER_INTERVAL_SECONDS=20
```

## Шаг 6. Установите всё нужное для бота

Вернитесь в терминал в папке проекта и выполните:

```bash
uv sync
```

Подождите, пока команда завершится. В первый раз она скачает Python-библиотеки и базу часовых поясов. Обычно это нужно сделать только один раз.

## Шаг 7. Запустите бота

В той же папке выполните:

```bash
uv run main.py
```

Если вы увидели строку с текстом `Start polling`, значит бот запущен и ждёт сообщения.

Не закрывайте это окно, пока хотите получать тренировки и напоминания.

## Шаг 8. Откройте своего бота

1. В Telegram откройте бота, которого создали через @BotFather.
2. Нажмите **Start** или отправьте команду:

   ```text
   /start
   ```

3. Нажмите значок `/` рядом с полем ввода, чтобы увидеть меню команд.

Готово — можно настраивать тренировки.

# Первая настройка тренировок

Лучше делать всё по порядку: сначала группы мышц, затем упражнения, затем тренировочные дни.

## 1. Добавьте группу мышц

Отправьте команду:

```text
/newgroup
```

Бот попросит написать название. Например:

```text
Спина
```

Повторите для других групп: «Грудь», «Ноги», «Плечи», «Бицепс» и так далее.

Посмотреть созданные группы можно командой:

```text
/groups
```

## 2. Добавьте упражнения

Отправьте:

```text
/newexercise
```

Дальше бот будет задавать простые вопросы:

1. Для какой группы мышц упражнение.
2. Как называется упражнение.
3. Сколько подходов делать по умолчанию.
4. Какая цель одного подхода: например, `8–12 повторений`, `10 повторений` или `40 секунд`.
5. Сколько отдыхать между подходами.

Пример:

```text
Группа: Спина
Название: Подтягивания
Подходы: 3
Цель: 8–12 повторений
Отдых: 90 секунд
```

Список всех упражнений:

```text
/exercises
```

## 3. Создайте тренировочный день

Отправьте:

```text
/newday
```

Бот предложит:

1. Написать название тренировки, например `Спина + бицепс`.
2. Выбрать дни недели. Кнопка **Каждый день** отмечает все дни сразу.
3. Написать время, например `18:30`.
4. Выбрать группы мышц для этого дня.
5. Выбрать количество упражнений из каждой выбранной группы.

После этого бот будет автоматически собирать тренировку в выбранные дни и присылать её в указанное время.

Посмотреть или удалить тренировочные дни:

```text
/days
```

> Если у вас несколько тренировочных дней на одну дату, бот пришлёт план для каждого из них.

# Как провести тренировку

## Получить тренировку прямо сейчас

Если сегодня есть запланированный тренировочный день, отправьте:

```text
/today
```

Бот пришлёт ваш план на сегодня. Это удобно, если не хочется ждать времени напоминания.

Если на сегодня ничего не запланировано, бот так и напишет.

## Отмечать подходы

В сообщении с тренировкой есть кнопки подходов. Нажимайте их после выполнения очередного подхода.

- Когда закрыты все подходы упражнения, упражнение отмечается как выполненное.
- Когда закрыты все упражнения, тренировка считается завершённой.
- После завершения бот обновит серию тренировок и может прислать короткое поздравление.

Если тренировка не завершена, бот может прислать дружеское напоминание спустя несколько часов после запланированного времени и вечером.

# Статистика

Откройте её командой:

```text
/stats
```

В статистике есть:

- текущая серия тренировочных дней;
- лучший результат серии;
- количество выполненных тренировок;
- количество закрытых упражнений и подходов;
- процент выполнения плана;
- календарь **текущего месяца**.

Обозначения в календаре:

```text
✅ выполнено
◐ частично
✕ пропущено
* сегодня в процессе
```

## Сброс статистики

Под календарём находится ссылка **«Сбросить статистику»**.

1. Нажмите её.
2. Бот отдельно спросит, действительно ли нужно всё удалить.
3. Нажмите **«Да, сбросить»** только если уверены.

При сбросе удаляются история тренировок, выполненные подходы, серии и календарь. **Группы мышц, упражнения и тренировочные дни сохраняются.**

Отменить уже подтверждённый сброс нельзя.

# Часовой пояс

Время тренировок задаётся относительно московского времени.

Сначала отправьте:

```text
/timezone
```

Бот покажет текущую настройку и примеры. Чтобы изменить её, укажите разницу с Москвой:

```text
/timezone 0
```

— московское время.

```text
/timezone +1
```

— на час впереди Москвы, например Самара.

```text
/timezone -1
```

— на час позади Москвы, например Калининград.

Доступны значения от `-1` до `+9`.

> Настройка сохраняется отдельно для каждого пользователя Telegram. Если ботом пользуются несколько человек, каждый выбирает своё время сам.

# Все команды

| Команда | Что делает |
| --- | --- |
| `/start` | Начинает работу и показывает приветствие. |
| `/help` | Показывает подсказку по командам. |
| `/today` | Показывает тренировку, назначенную на сегодня. |
| `/stats` | Открывает статистику и календарь текущего месяца. |
| `/groups` | Показывает группы мышц. |
| `/newgroup` | Создаёт группу мышц. |
| `/exercises` | Показывает упражнения. |
| `/newexercise` | Добавляет упражнение. |
| `/days` | Показывает тренировочные дни. |
| `/newday` | Создаёт тренировочный день. |
| `/timezone` | Показывает или меняет разницу времени с Москвой. |
| `/cancel` | Отменяет незавершённое создание группы, упражнения или тренировочного дня. |

# Как остановить и снова запустить бота

## Остановить

Перейдите в окно терминала, где работает бот, и нажмите:

```text
Ctrl + C
```

## Запустить снова

Откройте терминал в папке проекта и выполните:

```bash
uv run main.py
```

Ваши упражнения, планы и статистика останутся на месте: они хранятся в файле `workout_bot.db` в папке проекта.

---

# Резервная копия

Чтобы не потерять данные, иногда делайте копию файла:

```text
workout_bot.db
```

Перед копированием лучше остановить бота через `Ctrl + C`. Затем просто скопируйте файл `workout_bot.db` в другое место: на флешку, в облачное хранилище или на другой диск.

Чтобы восстановить данные, остановите бота и замените файл `workout_bot.db` сохранённой копией.

# Если что-то не работает

## После запуска бот не отвечает

Проверьте по порядку:

1. Окно терминала с ботом всё ещё открыто.
2. В терминале есть строка `Start polling`.
3. Токен в `.env` скопирован полностью и без лишних пробелов.
4. Вы пишете именно тому боту, которого создали в @BotFather.
5. После изменения `.env` вы остановили и снова запустили бота.

## Появилась ошибка про `tzdata` или часовой пояс

В папке проекта снова выполните:

```bash
uv sync
```

Затем запустите бота заново:

```bash
uv run main.py
```

## Бот не присылает тренировку сам

Проверьте:

1. Создан ли тренировочный день через `/newday`.
2. Выбран ли для него сегодняшний день недели.
3. Указано ли время, которое уже наступило.
4. Правильно ли настроен часовой пояс через `/timezone`.
5. Запущен ли бот и не закрыто ли окно терминала.

Можно не ждать напоминания и отправить `/today`.

## Нужно начать создание заново

Во время добавления группы, упражнения или тренировочного дня отправьте:

```text
/cancel
```

Бот отменит только незавершённое действие. Уже сохранённые данные не удаляются.
